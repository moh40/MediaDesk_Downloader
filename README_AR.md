# MediaDesk v0.2.0 — روابط صفحات الفيديو (نسخة تجريبية)

هذا المشروع عبارة عن تطبيق Windows WPF مستقل عن Android، ولكنه **ليس نسخة مطابقة لـ Snaptube**.

## ما أضيف في v0.2.0
- الاحتفاظ بواجهة v0.1.1 المصغّرة (675×465).
- تصحيح ربط Progress ليستخدم Mode=OneWay منعًا لخطأ WPF السابق.
- الاحتفاظ بمحرك روابط HTTP/HTTPS المباشرة.
- إضافة دعم تجريبي لروابط صفحات الفيديو الشائعة (YouTube/Shorts، TikTok، Instagram، Facebook، Vimeo، إلخ) عبر **yt-dlp.exe**. الدعم يعتمد على الموقع، وتحديث yt-dlp، وتوفر الفيديو للتحميل؛ لا يوجد ضمان بأن كل رابط يعمل.
- دعم محاولات التنزيل المتقطعة من yt-dlp وإيقاف/استئناف العملية، وظهور الملف النهائي في مكتبة الوسائط بعد اكتماله.
- تثبيت yt-dlp من إصدار GitHub الرسمي مع فحص SHA-256 والتحقق من تطابق الملف.
- إعادة استخدام ffmpeg من PATH لدمج الفيديو والصوت عندما يتطلب ذلك؛ إذا لم يكن مثبتًا فقد تفشل بعض الصيغ. يجب تحميل ffmpeg بشكل منفصل إذا لزم.

## تثبيت تحديث المشروع
1. أغلق MediaDesk، ثم شغّل `apply-mediadesk-v0.2.ps1` من ملف التحديث ZIP.
2. السكربت ينشئ نسخًا احتياطية من ملفات المشروع، ويستبدل فقط ملفات الكود المحددة.
3. يشغّل `setup-video-tools.ps1` لتنزيل yt-dlp من GitHub والتحقق منه، ثم يبني نسخة EXE جديدة.
4. افتح `D:\MediaDesk-Windows\release\win-x64\MediaDesk.exe`.

يمكن تثبيت الأداة يدويًا من المشروع بعد فك ضغطه:

```powershell
set-location 'D:\MediaDesk-Windows'
powershell -executionpolicy bypass -file .\setup-video-tools.ps1
powershell -executionpolicy bypass -file .\build.ps1
```

ملف `yt-dlp.exe` المساعد يكون في `release\win-x64\tools\yt-dlp.exe`. لذا يلزم **نقل مجلد release كاملًا** إذا أردت تشغيل وظائف صفحات الفيديو على جهاز آخر. لا يلزم تثبيت Android أو محاكي. ملف EXE الخاص بالبرنامج نفسه مستقل عن تثبيت .NET Runtime.

## قيود مهمة
- التطبيق يوجه روابط مواقع الفيديو المعروفة إلى yt-dlp. أما الروابط المباشرة الأخرى فتمر عبر محرك HTTP الأصلي. لا يوجد اكتشاف شامل لجميع مواقع الفيديو بعد.
- لا يدعم اختيار جودة محددة أو التحويل إلى MP3 أو المتصفح المدمج حتى الآن.
- قد ترفض المواقع التنزيلات بسبب سياساتها أو قيودها الفنية أو ضرورة تسجيل الدخول، ولن يتجاوز التطبيق حماية DRM.
- بعض خدمات الفيديو الحديثة تحتاج إصدارًا جديدًا من yt-dlp وJavaScript runtime مناسبًا وffmpeg. أي عطل في تنزيل صفحات الفيديو لا يعني بالضرورة وجود عطل في واجهة التطبيق.
- احترم حقوق أصحاب المحتوى وشروط المنصات؛ استخدم الميزة للوسائط المصرح بتنزيلها فقط.
- **لم يتم تجميع نسخة Windows أو إجراء اختبار تشغيل هنا**. هذا تحديث مصدر مع فحوص ساكنة، وسيحتاج إلى `dotnet publish` على جهازك.

## الاستكشاف
إذا أغلق التطبيق أو فشل التنزيل، راجع `%LOCALAPPDATA%\MediaDesk\errors.log`، واحذف أي بيانات حساسة قبل مشاركة السجل.
